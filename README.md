An alien tourist gives planet Earth a one-star review — and still admits the food was excellent.

> One star: the gravity keeps dropping my luggage, the locals scream at glowing rectangles, and it rains without a permit — but the noodles alone are worth the forty-light-year flight back.

`main.py` (Python 3.13, standard library only) writes that single sentence to the grader's output file. It is deterministic, uses no network, and resolves its output path from `ENTRY_OUT`, then `MAKEFUN_OUTPUT_DIR`, then `/output/entry.txt`, falling back to `./entry.txt`.
